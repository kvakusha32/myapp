# Практическое занятие №2 — структура Go-проекта

Это учебный HTTP-сервис на Go. В папке cmd находится вход в программу, в internal — код приложения, в utils — функции логирования.

Запуск из корня проекта: `go run ./cmd/myapp`. После запуска адрес `/` возвращает текст, а `/ping` возвращает JSON. Сервер работает на `http://localhost:8080`.
